dotclipforge

Privacy Policy

Last updated: October 16, 2026

dotclipforge is a desktop tool run by Tristan M. on a personal computer. It has a single user: its owner. This page describes the data the tool handles when it is connected to a TikTok account.

Data received from TikTok

  • Basic profile information (scope user.info.basic): open ID and display name of the connected account. The display name is shown once after login, so the owner can check the right account is connected.
  • Access and refresh tokens issued by TikTok after the owner authorizes the app.
  • Upload status of each video sent as a draft (publish ID and status).

Where the data is stored

Everything is stored locally, on the owner's computer only: tokens in a local file, upload statuses in a local database. dotclipforge has no server. No data is sent anywhere except to the TikTok API, to upload videos as drafts and check their status.

What dotclipforge does not do

  • It does not sell, share or transfer any data to third parties.
  • It does not use analytics, advertising or tracking. This website sets no cookies.
  • It does not post on its own: videos arrive as drafts, and the owner publishes them manually in the TikTok app.
  • It does not access the data of any TikTok user other than the connected account.

Retention and deletion

Tokens are kept until the authorization is revoked or the local file is deleted. Access can be revoked at any time in the TikTok app, under Settings and privacy, Security and permissions, Apps and services permissions. Deleting the local data folder removes everything the tool stored.
